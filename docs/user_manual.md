# EIDOLON Researcher User Manual

## Interface Sections
1. **Command Centre (A)**: Real-time telemetry (population, tick/season/year, cooperation index, network density, Gini, scarcity prices, and live event stream).
2. **Society Explorer (B)**: Interactive 3D WebGL (`InstancedMesh`) and 2D Grid views. Orbit/zoom/pan, color agents by action, emergent community, or need satisfaction, filter by location/community, and click any agent to inspect.
3. **Agent Observatory (C)**: Full internal inspection of an agent's Big Five traits, 8 needs, goals, beliefs, 4-layer memory counts, Q-learning records, relationships, and **Decision Explainability & Replay** (factor breakdown + runner-up alternatives + decision timeline slider).
4. **Social Network (D)**: Relationship & trust graph, minimum-trust filter, NetworkX degree centrality rankings, and active rule-governed institutions (treasury, compliance, stability).
5. **Research Lab (E)**: Configure and launch new experiments, patch live parameters mid-run (learning rate, exploration rate, cooperation synergy, climate severity), and manage saved experiments (select, duplicate with new seed, delete).
6. **Emergence (F)**: Automated detectors reporting measured baseline-vs-current changes with exact statistical/graph methods.
7. **Data & Analytics (G)**: Interactive Plotly time-series charts and one-click export of JSON bundles, CSV metrics, and Matplotlib PNG reports.
8. **Scenarios & Snapshots (H)**: Launch any of the 8 prebuilt scientific scenarios, save versioned snapshots, restore exact simulation states, or create local SQLite database backups.
9. **Compare Trials (I)**: Compare two saved experiments side-by-side or run paired multi-seed controlled trials computing mean, variance, 95% confidence intervals, and paired t-test p-values.
10. **Diagnostics (J)**: Monitor tick latency, theoretical TPS, RSS memory, SQLite size, active subsystems, and runtime error logs.
